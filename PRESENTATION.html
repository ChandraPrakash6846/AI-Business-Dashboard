DATA ENGINEERING DEEP-DIVE

Automated Data Health & Cleaning Pipeline

Detailed technical breakdown of modules/data_processor.py:

🛠️ Cleaning Algorithm Workflow

  1. Header Normalization: Strips leading/trailing whitespace from column titles.
  2. Duplicate Purging: Evaluates df.duplicated().sum() and drops identical rows.
  3. Automatic Datetime Parsing: Scans string columns containing date, time, day, month, created and attempts pd.to_datetime(col, errors='coerce'). If >50% non-null, converts column to datetime.
  4. Smart Imputation Engine:
    • Numerical columns ➔ fillna(median)
    • Categorical columns ➔ fillna(mode[0])
    • Datetime columns ➔ bfill().ffill()
Robustness: Prevents app crashes on dirty datasets with missing or malformed inputs.

💻 Core Cleaning Code Snippet

def clean_and_validate(df):
    cleaned_df = df.copy()
    cleaned_df.columns = [str(c).strip() for c in cleaned_df.columns]
    
    # Remove Duplicates
    cleaned_df = cleaned_df.drop_duplicates()
    
    # Impute Missing Values
    for col in cleaned_df.columns:
        if pd.api.types.is_numeric_dtype(cleaned_df[col]):
            cleaned_df[col] = cleaned_df[col].fillna(cleaned_df[col].median())
        elif pd.api.types.is_datetime64_any_dtype(cleaned_df[col]):
            cleaned_df[col] = cleaned_df[col].bfill().ffill()
        else:
            mode_val = cleaned_df[col].mode()
            cleaned_df[col] = cleaned_df[col].fillna(mode_val[0] if not mode_val.empty else "Unknown")
            
    return cleaned_df, health_report
MACHINE LEARNING DEEP-DIVE

Machine Learning Anomaly Scan & Statistical Engine

Detailed technical breakdown of modules/ai_engine.py:

🚨 Isolation Forest Anomaly Detection

Unlike traditional z-score thresholding which evaluates columns independently, IsolationForest isolates anomalies by randomly selecting a feature and split value, building an ensemble of isolation trees.

  • Feature Space: All numerical columns in dataset.
  • Contamination Rate: Set to 0.05 (top 5% most anomalous records).
  • Decision Logic: Anomalies require fewer splits to isolate (shorter tree path length).
model = IsolationForest(contamination=0.05, random_state=42)
df_result['is_anomaly'] = model.fit_predict(df_clean) == -1

🔥 Pearson Correlation Matrix Engine

Calculates exact pairwise correlation coefficients \( r \):

\[ r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \sum (y_i - \bar{y})^2}} \]

  • Calculates absolute correlation matrix across numerical variables.
  • Fills diagonal matrix with zeros to ignore self-correlation.
  • Flags high correlation pairs (\(|r| > 0.70\)) for executive insights.
Insight Output: Identifies collinearity & hidden statistical drivers automatically.
NLP & QUERY PARSER DEEP-DIVE

Natural Language Query Engine Pipeline

How plain text questions are processed into filtered DataFrames and dynamic Plotly charts:

🔍 Query Processing Pipeline Steps

  1. Tokenization & Normalization: Converts input to lowercase and strips special characters.
  2. Column Intent Mapping: Scans query against get_smart_column_mapping() dictionary to identify target metric (Sales, Profit, Quantity).
  3. Grouping & Dimension Detection: Checks for keywords like "by category", "by region", "over time".
  4. Value Filter Matching: Iterates over unique categorical values to apply exact string filters (e.g., Category == "Technology").
  5. Chart Type Selection: If grouping by time, selects Line Chart; if grouping by category, selects Bar Chart.
Zero Dependency: Runs 100% offline without external LLM API costs or latency.

💻 Natural Language Query Parser Logic

def process_natural_language_query(query, df):
    q = query.lower().strip()
    mapping = get_smart_column_mapping(df)
    
    # Detect target numerical metric
    target_metric = mapping.get("sales") or num_cols[0]
    
    # Detect group dimension
    if "by category" in q:
        group_col = mapping.get("category")
    elif "over time" in q:
        group_col = mapping.get("date")
        chart_type = "line"
        
    # Group & Aggregate Pandas Dataframe
    agg_df = df.groupby(group_col)[target_metric].sum().reset_index()
    return agg_df, chart_type, summary, group_col, target_metric
